# Incentivio

> Incentivio is a Boston-based digital guest engagement platform for multi-unit restaurant brands, unifying branded online ordering, loyalty, gift cards, marketing automation and guest analytics. Incentivio publishes no public developer documentation, but two production services expose live, unauthenticated OpenAPI definitions on Incentivio's own hosts: a guest-facing Mobile & Ordering API (125 operations) and an operator-facing Admin API (421 operations). Both sit behind an OAuth 2.0 authorization server that publishes RFC 8414 metadata anonymously.

Generated by API Evangelist from probed and harvested artifacts. Incentivio does not publish an llms.txt of its own — https://incentivio.com/llms.txt and https://apidocs.incentivio.com/llms.txt both return 404.

## What an agent needs to know first

- Every call is scoped to a restaurant brand tenant. The mobile API takes a `CLIENTID` header; the admin API takes `Inc-Client-Id` (and sometimes `Inc-Merchant-Id`). Without it, endpoints return 400 or 500, not a useful message.
- Authentication is an OAuth 2.0 bearer token. Unauthenticated calls return `401` with `WWW-Authenticate: Bearer realm="restservice"`.
- Errors have an EMPTY BODY. The outcome is carried in the `incentivio-code` and `incentivio-message` response headers. Reading only the body tells you nothing.
- There are no rate-limit headers, no idempotency keys, and no declared 4xx/5xx responses in either definition. Payment operations are POST with no replay protection.
- There is no public sign-up. Access is arranged through partnership or enterprise onboarding.

## APIs

- [Mobile & Ordering API](https://mobile.incentivio.com/incentivio-mobile-api): guest-facing REST API behind order.incentivio.com. Catalogs and menus, locations and stores, orders and order items, payments and payment instruments, gift cards, wallets, loyalty accounts and points, offers and discounts, surveys, segments, messaging, user accounts. OpenAPI 3.0.1, 112 paths, 125 operations, 285 schemas.
- [Admin API](https://adminapi.incentivio.com/incentivio-admin-api): operator-facing REST API behind admin.incentivio.com. Client and merchant configuration, stores and locations, menu import and menu intelligence, campaigns and offer distribution, guest journeys and personas, segments and tags, loyalty administration, gift card issuance and ACH funding, payments, refunds, fund transfers, Spreedly connectors, role and module permissions, and a large CSV-capable reporting surface. OpenAPI 3.1.0, 327 paths, 421 operations, 621 schemas.
